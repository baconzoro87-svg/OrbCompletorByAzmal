# OrbCompletorByAzmal

A single-file Discord bot that auto-completes **Discord orb quests** on linked accounts.

Prefix: `*`  
Author: **Azmal**

---

## Quick Start

```bash
git clone https://github.com/baconzoro87-svg/OrbCompletorByAzmal.git
cd OrbCompletorByAzmal
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
nano .env      # fill BOT_TOKEN and OWNER_ID
python3 bot.py
